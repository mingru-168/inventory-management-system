# BOM 配置模块使用文档

- **模块完整名称**：材料审核 - BOM（BOM-配置）
- **适用版本**：BOM 配置功能交付后
- **服务地址**：<http://localhost:3000>

---

## 一、功能定位

用于**新增与维护生产材料的定额定义（BOM）**，即针对某一产品型号/名称，配置其生产所需的材料清单（含型号、类型、工序、规格、颜色、用量、单位等）。BOM 配置供后续生产计划、材料审核和用料核对调用。

---

## 二、入口与权限

### 2.1 进入路径

侧边栏点击 **采购管理** → **BOM-按配置**

### 2.2 权限要求

| 操作 | 所需权限（模块 / 功能 / 动作） |
| --- | --- |
| 新增 BOM | 采购管理 / 材料审核 / **添加** |
| 编辑 BOM | 采购管理 / 材料审核 / **编辑** |
| 删除 BOM | 采购管理 / 材料审核 / **删除** |

> 无对应权限时，接口返回 403；页面按钮的可见性由系统权限体系控制。

---

## 三、主列表页

进入页面后显示：

- **页面标题**：BOM-配置
- **副标题**：新增 / 维护生产材料定额定义
- **搜索框**：可按 型号 / 名称 / 颜色 / 规格 / 台面颜色 / 版本说明 模糊搜索，输入即时过滤
- **「+ 新增 BOM」按钮**：右上角，打开新增弹窗

表格列（从左到右）：

| 型号 | 名称 | 颜色 | 规格 | 台面颜色 | 版本说明 | 材料数 | 操作 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 产品型号 | 产品名称 | 产品颜色 | 产品规格 | 台面颜色 | 版本说明文本 | 该 BOM 的材料条数 | 编辑 / 删除 |

无数据时显示空状态提示「暂无 BOM 配置，点击右上角「+ 新增 BOM」创建」。

---

## 四、新增 / 编辑 BOM

点击「+ 新增 BOM」打开新增弹窗；点击某行的「编辑」打开编辑弹窗（字段已回填）。

### 4.1 产品信息字段

| 字段 | 说明 | 是否必填 |
| --- | --- | --- |
| 产品型号 * | 可手动输入或从产品资料选择（输入时弹出匹配建议） | 是 |
| 产品名称 * | 可手动输入或从产品资料选择（输入时弹出匹配建议） | 是 |
| 颜色 | 可手动输入或从产品资料选择 | 否 |
| 规格 | 可手动输入或从产品资料选择 | 否 |
| 台面颜色 | 可手动输入或从产品资料选择 | 否 |
| 版本说明 | 自由文本，如「v1 初始版」「v2 调整用量」 | 否 |

**打通关联数据源：**
- 这 5 个字段均可**手动输入任意内容**，不限于下拉选项；输入时若与产品资料匹配，会出现**候选建议**，点击可快速填入。
- **联动带出**：在「产品型号」或「产品名称」中选定/输入某产品（如型号 375）后，系统自动从产品数据源带出该产品对应的**颜色、规格、台面颜色**（如黑色 / 80cm / 纳秋绿），减少重复录入。
- 若输入的内容在产品资料中无匹配，则不会联动带出，颜色/规格/台面颜色可单独手动填写。

### 4.2 参照导入

- **参照产品**：选择已有的 BOM 产品，仅作记录参考（不自动导入）。
- **参照配置项**：选择已有 BOM 后点击，**自动把它的材料明细导入到当前材料表格**（覆盖当前明细，会二次确认）。

适用于「新产品结构与旧产品相似」时快速复制材料清单。

### 4.3 材料明细表（可编辑）

每条材料一行，列为：

| 操作 | 序号 | 材料名称 | 型号 | 类型 | 工序 | 规格 | 颜色 | 用量 | 单位 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| ×（删除该行） | 数字 | 文本 | 文本 | 文本 | 文本 | 文本 | 文本 | 数字（支持小数） | 文本 |

- 新增 BOM 时默认有一行空白材料（序号 1）。
- 点击「**+ 添加材料**」新增一行，序号自动递增。
- 点击行内「×」删除该行。
- 所有单元格均可直接编辑。

### 4.4 保存

点击「保存」提交，校验产品型号与名称为空则会拦截。保存成功后关闭弹窗、刷新列表并弹出成功提示（新增：BOM 已创建；编辑：BOM 已更新）。

---

## 五、删除

点击某行「删除」→ 确认「确定删除该 BOM 配置？」→ 确认后删除并刷新列表，弹出「已删除」提示。

---

## 六、相关后端接口（供集成 / 调用）

所有接口均需登录鉴权，三类写操作分别需要 `采购管理 / 材料审核` 的 添加 / 编辑 / 删除 权限。

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/bom-configs` | 查询全部 BOM 配置 |
| POST | `/api/bom-configs` | 新增 BOM（产品型号、名称必填） |
| PUT | `/api/bom-configs/:id` | 编辑指定 BOM |
| DELETE | `/api/bom-configs/:id` | 删除指定 BOM |

材料明细结构（`materials[]`）：

| 字段 | 含义 |
| --- | --- |
| `seq` | 序号 |
| `name` | 材料名称 |
| `model` | 型号 |
| `type` | 类型 |
| `process` | 工序 |
| `spec` | 规格 |
| `color` | 颜色 |
| `quantity` | 用量 |
| `unit` | 单位 |

BOM 记录字段：`id`、`productModel`、`productName`、`color`、`spec`、`tabletopColor`、`version`、`refProduct`、`refBomId`、`materials`、`creator`、`createdAt`（编辑时含 `modifier`、`updatedAt`）。

> 新增 / 编辑 / 删除均会写入操作日志（操作日志页「系统管理 → 操作日志」可查）。

## 七、常见问题

1. **产品下拉为空 / 无选项？**
   需先在「产品资料」中录入产品，本页面下拉选项从产品资料自动去重生成。

2. **参照配置项导入后原明细不见了？**
   导入采用覆盖方式，导入前会弹出确认「导入将覆盖当前材料明细」，确认后原明细被替换。如需保留请先手动记录。

3. **用量可以填小数吗？**
   可以，用量输入框支持小数（如 0.5）。

4. **普通用户看不到新增 / 编辑 / 删除按钮？**
   当前账号缺少 `材料审核` 的 添加 / 编辑 / 删除 权限，请联系管理员在角色权限中授权。
