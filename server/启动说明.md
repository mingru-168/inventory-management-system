# ERP系统 SQLite 数据库启动说明

## 已完成的工作

1. ✅ 安装SQLite依赖（better-sqlite3）
2. ✅ 创建SQLite数据库连接模块（db_sqlite.js）
3. ✅ 创建SQLite版本API服务器（index_sqlite.js）
4. ✅ 创建数据迁移脚本（migrate_sqlite.js）
5. ✅ 迁移现有数据到SQLite
6. ✅ 测试数据库连接和API

## 数据库文件位置

- SQLite数据库文件：`e:\生产力\server\erp.db`
- 数据文件备份：`e:\生产力\server\data.json`（原始JSON文件保留）

## 启动步骤

### 1. 迁移数据（如需要）

如果数据库文件不存在或需要重新迁移数据：

```bash
cd "e:\生产力\server"
node migrate_sqlite.js
```

这将从 `data.json` 迁移所有数据到 `erp.db`

### 2. 启动服务器

```bash
cd "e:\生产力\server"
npm start
```

或直接运行：

```bash
cd "e:\生产力\server"
node index_sqlite.js
```

服务器将在 http://localhost:3000 启动

## 可用命令

- `npm start` - 启动SQLite版本的服务器
- `node migrate_sqlite.js` - 重新迁移数据

## 已创建的API端点

### 产品管理
- `GET /api/products` - 获取所有产品
- `POST /api/products` - 创建产品
- `PUT /api/products/:id` - 更新产品
- `DELETE /api/products/:id` - 删除产品

### 销售订单
- `GET /api/sales-orders` - 获取所有销售订单
- `GET /api/sales-orders/:id` - 获取单个订单
- `POST /api/sales-orders` - 创建订单
- `PUT /api/sales-orders/:id` - 更新订单
- `PUT /api/sales-orders/:id/status` - 更新订单状态
- `DELETE /api/sales-orders/:id` - 删除订单

### 其他模块
- `/api/customers` - 客户管理
- `/api/suppliers` - 供应商管理
- `/api/inventory` - 库存管理
- `/api/purchase-orders` - 采购订单
- `/api/production-orders` - 生产订单
- `/api/finance-records` - 财务记录
- `/api/warehouses` - 仓库管理
- `/api/dashboard` - 仪表板数据

## 数据库表结构

- `products` - 产品清单
- `product_spec_prices` - 产品规格价格
- `inventory` - 库存
- `customers` - 客户
- `sales_orders` - 销售订单
- `sales_order_items` - 销售订单明细
- `suppliers` - 供应商
- `purchase_orders` - 采购订单
- `purchase_order_items` - 采购订单明细
- `production_orders` - 生产订单
- `finance_records` - 财务记录
- `warehouses` - 仓库
- `users` - 用户

## 注意事项

- SQLite数据库文件是轻量级的，无需额外安装数据库服务器
- 数据库文件 `erp.db` 可以直接备份和迁移
- 所有数据都以SQLite格式存储在单个文件中
- 支持完整的SQL查询能力
- 自动创建所有必要的表结构
